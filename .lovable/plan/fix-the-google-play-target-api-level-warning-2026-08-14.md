# Fix the Google Play "target API level" warning

Google is not complaining about your app's code. It is complaining about the Android
wrapper that PWABuilder generated: it was built against an older Android target API
level. The fix is a rebuild + reupload of the Android package — no changes to the
website or app code.

## What is happening

- Play requires every app updated after Aug 31, 2026 to target within 1 year of the
  latest Android release (currently `targetSdkVersion 36`, minimum accepted 35).
- Your Play listing (`com.jambcrash.ai`) was generated by PWABuilder some time ago,
  so its `build.gradle` still targets an older SDK.
- Your existing listing keeps working; you just cannot ship updates until you upload
  a package with a newer target.

## Steps (all outside this project)

1. Go to pwabuilder.com and enter `https://jamb-crash-ai.vercel.app/`.
2. Package for Android. In the Android options, before generating:
   - Package ID must be exactly `com.jambcrash.ai` (same as the Play listing).
   - Host / origin: `jamb-crash-ai.vercel.app`.
   - App name, launcher name, theme colors: keep the same as the current listing.
   - Signing key: choose "Use mine" and upload the **same keystore** used for the
     original release. A new key will be rejected by Play.
   - Bump the version code above the one currently live in Play.
3. Download the zip. The freshly generated project targets the current SDK, which is
   what clears the warning.
4. Upload the `.aab` to Play Console as a new release, and roll out.
5. After rollout, uninstall and reinstall from Play to confirm both the warning is
   gone and the URL bar stays hidden (asset links are already live and verified).

## If you no longer have the original keystore

You cannot sign with a new key unless Play App Signing is enabled on the listing.
If it is enabled, you can request an upload key reset in Play Console
(Setup > App integrity > Request upload key reset) and then sign with a new key.

## Code changes in this project

None required. The web app, manifest, and `/.well-known/assetlinks.json` are already
correct for the rebuilt package.
